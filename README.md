**WICKLIGHT** — a top-down stealth game. Wick, the lamplighter's apprentice, climbs the Black Lighthouse to steal back the starlight the Keepers locked away. Three floors, 21 shards of starlight, one Starlight Heart, 18 patrolling Keepers with vision cones, and the great lamp's sweeping beam.

The signature is the **Kindled Lantern**: kindle it and you see far — but you glow far. Douse it and you melt into the dark — but you go half-blind. Spend an ember on a **flare** and every Keeper near you stands dazzled. Bushes hide you, crates block their eyes, lamplight betrays you, and running is loud.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, just static files under `game/`.

Controls: **WASD / arrows** move · **Shift** run (loud) · **Q** douse/kindle the lantern · **F** flare (dazzles Keepers, costs 1 ember) · **P** pause · **M** mute · **R** restart the floor · **Enter / click** menus.
